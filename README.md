# FundPatients — Web Frontend

Next.js 16 App Router rebuild of the FundPatients medical-crowdfunding platform. See [CLAUDE.md](./CLAUDE.md) for stack, route structure, and environment variables.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

You'll need a `.env.local` with the Supabase and payment provider keys listed in `CLAUDE.md`.

## Deployment

Deployed to [Vercel](https://vercel.com/true-lite/fundpatients-mvp), auto-deploying from `main`.
